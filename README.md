# 🏢 企业人事管理系统 (HRMS)

> 基于 SpringBoot + Vue + MySQL 的前后端分离人事管理系统。

### 🛠️ 技术栈
* **后端**：Java SpringBoot, MyBatis-Plus
* **前端**：Vue.js, ElementUI, Axios
* **数据库**：MySQL 5.7+
* **部署**：Nginx 反向代理

### ✨ 功能模块
1.  **员工管理**：员工信息的增删改查、入职离职处理。
2.  **公告管理**：发布公司通知、政策公告。
3.  **考勤打卡**：员工在线打卡、考勤记录查询。
4.  **数据可视化**：首页展示招聘人数、员工分布等图表。

### 🚀 快速开始
1.  克隆项目到本地。
2.  导入 `db.sql` 到 MySQL 数据库。
3.  修改 `application.yml` 中的数据库配置。
4.  启动 SpringBoot 后端，访问 `localhost:8080`。
